### [BEopt Building Energy Simulation Automation & DOE Pipeline](https://github.com/TajwarFahmid/Green-Building-Project)
**Python | SQLite3 | Pandas | OpenPyXL | NREL BEopt & EnergyPlus Engine**

Engineered a headless batch automation and ETL pipeline to programmatically generate, validate, and execute **120 full-scale Design of Experiments (DOE)** energy retrofits for building decarbonization modeling.

- **Programmatic Archive Engineering:** Dynamically deconstructed and repackaged `.BEopt` zip-container files, programmatically mapping 10 multi-dimensional factors (HVAC SEER/HSPF, envelope R-values, infiltration, window SHGC, lighting) directly into embedded SQLite project databases.
- **Automated Verification Engine:** Built an embedded SQLite inspector to validate discrete factor assignments, GUID referential integrity, and default fallbacks prior to computation.
- **Headless Pipeline Orchestration:** Automated batch execution across the EnergyPlus simulation engine, dynamically parsing complex output tables to extract site energy (kWh), gas consumption (therms), and utility cost metrics into clean datasets.
