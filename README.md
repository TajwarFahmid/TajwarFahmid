### [BEopt Building Energy Simulation Automation & DOE Pipeline](https://github.com/TajwarFahmid/Green-Building-Project)
**Python | SQLite3 | Pandas | OpenPyXL | NREL BEopt & EnergyPlus Engine**

Engineered a headless batch automation and ETL pipeline to programmatically generate, validate, and execute **120 full-scale Design of Experiments (DOE)** building energy retrofits for decarbonization modeling.

- **Programmatic Archive Engineering**: Dynamically deconstructed and repackaged `.BEopt` zip-container archives, mapping 10 multi-dimensional factors (HVAC SEER/HSPF, envelope R-values, infiltration ACH50, window SHGC, lighting) directly into embedded SQLite project databases.
- **Automated Verification Engine**: Built an embedded SQLite inspector (`verify_runs.py`) to validate discrete factor assignments, GUID referential integrity, and default fallbacks before triggering simulation runs.
- **Headless Pipeline Orchestration**: Automated multi-threaded batch execution across the EnergyPlus simulation engine, parsing output tables to extract site electricity (kWh), gas consumption (therms), and utility costs ($) into clean analytical datasets.

#### 💡 Multi-Disciplinary Impact:
